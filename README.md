# Strawberry Stationery

A charming and responsive stationery showcase website featuring a strawberry-inspired aesthetic, pastel colors, and a clean, modern interface.

## Overview

Strawberry Stationery is a front-end web project designed to showcase stationery products through an attractive and user-friendly interface. The website combines a soft strawberry-inspired visual theme with interactive product browsing, search functionality, and category filtering.

The project focuses on creating a pleasant browsing experience while demonstrating the core concepts of modern front-end web development.

## Features

- **Strawberry-Inspired Design:** A playful visual theme with soft colors and attractive styling.
- **Product Showcase:** Displays stationery products with images, descriptions, and prices.
- **Product Search:** Find products using the search functionality.
- **Category Filtering:** Filter products by stationery category.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Interactive Interface:** Dynamically updates displayed products based on search and category selections.
- **Simple Navigation:** Provides easy access to different website sections.
- **Lightweight Implementation:** Built using standard front-end technologies without requiring a backend.

## Product Categories

- Pens
- Pencils
- Pouches
- Notebooks
- Accessories

## Technologies Used

- **HTML5** — Structures the website content.
- **CSS3** — Provides styling, responsive layouts, and the strawberry-inspired theme.
- **JavaScript** — Implements product rendering, search, and category filtering.
- **Unsplash** — Provides externally hosted product imagery.
